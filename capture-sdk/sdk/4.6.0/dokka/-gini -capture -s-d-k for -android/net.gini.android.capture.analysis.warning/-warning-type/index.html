WarningType

@RestrictTo(value = RestrictTo.Scope.LIBRARY)
public enum WarningType

Represents the different warning scenarios that can be shown in the UI (e.g. inside WarningBottomSheet). Each enum value holds the resource IDs for its title, description and the labels of the primary CTA (filled, first button) and secondary CTA (outlined, second button), so that the UI can easily fetch localized strings when displaying the warning. The behavior behind the two CTAs is wired by the caller showing the sheet. Types whose title contains a format placeholder declare it via requiresTitleFormatArg, so the sheet can fail loudly when the argument is missing instead of rendering a literal placeholder. Types with a custom iconRes replace the sheet's default warning icon; a value of 0 keeps the default.
